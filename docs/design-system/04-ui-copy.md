# UI Copy — Bahasa Melayu (Formal)

## Tone Guidelines

- **Formal Malay** using "Anda" (not "Awak" or "Kamu")
- **Clear and direct** — shop staff need speed, not poetry
- **Consistent terminology** across all screens
- **English fallback** for technical terms where Malay is awkward (e.g., "Motherboard" not "Papan Induk")
- **Avoid abbreviations** in labels (OK in ticket numbers: "#D1-042")

## WhatsApp Messages (System-Generated)

These are the automated messages sent to customers. They must be clear, friendly, and actionable.

### Ticket Created
```
Salam [Nama],

Tiket #[Nombor] telah dicipta.
Peranti: [Model]
Cawangan: [Cawangan]

Kami akan nilaikan peranti anda dan hubungi anda sebentar lagi.

Terima kasih.
```

### Assessment Complete
```
Salam [Nama],

Penilaian untuk Tiket #[Nombor] telah selesai.

Masalah: [Diagnosis]
Anggaran: RM[Jumlah]
Tempoh: [Tempoh]

Balas **YA** untuk luluskan pembaikan.
Balas **TIDAK** untuk batal.
```

### Approval Confirmed
```
Tiket #[Nombor] — Pembaikan diluluskan!

Kami akan mulakan pembaikan segera.
Kami akan hubungi anda apabila siap.
```

### Repair Complete
```
🎉 Peranti anda sudah siap!

Tiket #[Nombor]
Peranti: [Model]
Pembaikan: [Diagnosis]

Sila ambil di:
[Cawangan], [Alamat]
Waktu operasi: 9 pagi - 7 malam

Tunjukkan mesej ini semasa pengambilan.
```

### Reminder (Unpicked Device)
```
⏰ Peringatan: Peranti [Model] anda masih belum diambil.

Tiket #[Nombor]
Tarikh akhir ambil: [Tarikh]

Sila ambil sebelum tarikh tersebut.
```

### Payment Receipt (Quick Repair / Voice / Full AI)
```
🔧 Repair Intake — Resit

Tiket #[Nombor]
[Model] — [Diagnosis/Isu]
Jumlah: RM[Jumlah] ([Kaedah])
Cawangan: [Cawangan]
Tarikh: [Tarikh], [Masa]

Terima kasih! Sila simpan resit ini.
```

### Retroactive Receipt (QR Subscribe)
```
📋 Resit Tiket #[Nombor] (dari [Tarikh])

[Model] — [Diagnosis/Isu]
Jumlah: RM[Jumlah]

Terima kasih! Langganan WhatsApp anda aktif.
Kami akan hantar kemaskini untuk lawatan seterusnya.
```
