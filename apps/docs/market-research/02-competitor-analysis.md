## Competitive Gap Summary

| Capability | RepairDesk | RepairShopr | RepairQ | CellSmart | Fixably | Orderry | RepairX |
|---|---|---|---|---|---|---|---|
| AI photo → device model | No | No | No | No | No | No | No* |
| Voice intake → ticket | No | No | No | No | No | No | No |
| WhatsApp quote/approval | No | No | No | No | Status only | No | No |
| QR code receipts | No | No | No | No | No | No | No |
| Mobile-first (iOS/Android) | No | No | No | No | Partial | Partial | No |
| Real-time tech queue | Basic | Basic | Yes | No | Yes | Yes | No |
| Role-based flows | Basic | Basic | Yes | No | Yes | Yes | No |
| Parts inventory | Yes | Yes | Yes | Yes | Yes | Yes | Yes |
| Payment capture | Yes | Yes | Yes | Yes | Yes | Yes | No |
| SaaS model | Yes | Yes | Yes | Yes | Yes | Yes | Yes |

*RepairX scans device via system connection (USB), not photo/camera.

**Key finding:** No existing competitor combines AI vision + voice intake + WhatsApp + QR receipts + mobile-first in a single product. The market is ripe for a mobile-first, AI-powered repair intake system that leverages WhatsApp (the dominant messaging platform in Southeast Asia) for both customer and staff communication.

---

## Our Competitive Advantages

1. **WhatsApp-native** — Core communication channel, not an afterthought. Customer YES/NO approval, staff assignments, daily summaries. Zero competitors use WhatsApp for repair workflow.

2. **AI triage intake** — Three tiers (Voice / Quick Repair / Full AI) that adapt to job complexity. No competitor has anything comparable. RepairX has AI but it's device-plug-in diagnostics, not intake.

3. **Mobile-first** — Staff use their own phones. No desktop needed at the counter. Only Orderry has a real mobile app and it's secondary.

4. **QR receipts** — Anonymous cash-and-go customers get a scannable receipt. Bridges the gap between "no phone number" and "still want to notify them." Zero competitors have this.

5. **Bahasa Melayu** — Full Malay UI and WhatsApp templates. No competitor supports Malay. This alone is a moat for Malaysia + Indonesia.

6. **Parts + POS built in** — Payment capture, inventory decrement, receipt generation. The system IS the POS for repairs. No parallel system needed.
