Repair Intake

Mobile UI Specs — Build Order

A

Flow A: Front Desk Intake (Full AI)

Login → Queue → Camera intake → AI device ID → Success → Technician assessment → Payment. 2-person handoff or solo technician.

B

Flow B: Quick Repair (Counter)

Typeahead device → quick-select issue → auto-approved → straight to In Progress. No camera, no AI vision. <10 seconds.

C

Flow C: Voice Intake

Speak into mic → AI extracts device, issue, customer, price → confirm → auto-approved. <5 seconds.

Key Design Principles

3 graduated intake tiers: Voice (<5s), Quick Repair (<10s), Full AI (30–90s)
Camera-first intake — inline 4:5 capture with amber corner brackets
Indigo primary (#4f46e5) + amber accent (#f59e0b) + teal secondary (#14b8a6)
AI suggestions as tappable radio cards with confidence %
Payment = POS: record, decrement stock, WhatsApp/QR receipt
Bahasa Melayu formal (DM Sans). No auto-translate — manual copy from 04-ui-copy.md
Offline-first: AsyncStorage queue with amber sync banner
